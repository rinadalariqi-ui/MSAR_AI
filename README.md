# MASAR Web Prototype

## التشغيل على Windows (VS Code)
1. فك ضغط الملف.
2. افتح مجلد `MASAR_Web` في VS Code.
3. افتح Terminal وأنشئ بيئة افتراضية (إذا لم تكن موجودة):
   `python -m venv .venv`
4. فعّلها من Command Prompt:
   `.venv\\Scripts\\activate.bat`
5. ثبّت المتطلبات:
   `python -m pip install -r requirements.txt`
6. شغّل الموقع:
   `python app.py`
7. افتح المتصفح على:
   `http://127.0.0.1:5000`

## تشغيل سريع
يمكنك أيضًا تشغيل `run_masar.bat` بالنقر المزدوج؛ سيُنشئ البيئة الافتراضية ويثبت المكتبات ثم يشغّل Flask تلقائيًا. اترك نافذة التشغيل مفتوحة أثناء استخدام الموقع.

## ملاحظات مهمة
- هذا نموذج ويب محلي أولي باستخدام Flask.
- تم الاحتفاظ بمحرك المطابقة وملفات البيانات من النموذج السابق.
- بيانات المنح العشرين الموجودة في CSV تجريبية، وروابط example.org ليست روابط تقديم حقيقية.
- نتيجة المطابقة قاعدة أهلية أولية وليست احتمال قبول.
- بيانات الملف الأكاديمي تحفظ محليًا في `data/profile.json` لأغراض التجربة.
